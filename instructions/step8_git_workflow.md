# Step 8: Git Workflow

1. Create a new feature branch from the main branch:

```bash
git checkout -b feature/directory-automation
```

2. Add and commit your changes:

```bash
git add .
git commit -m "Add Directory feature automation tests"
```

3. Push the branch to the remote repository:

```bash
git push origin feature/directory-automation
```

4. Create a pull request for code review and merging.

5. After approval, merge the pull request and delete the feature branch.
