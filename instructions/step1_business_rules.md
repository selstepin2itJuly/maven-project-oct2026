# Step 1: Testable Business Rules

**Context:**
- Application: https://opensource-demo.orangehrmlive.com/
- Feature: Directory
- Environment: QA

**Business Rules:**
1. Users with appropriate permissions can access and view the complete list of directories.
2. Users can perform a search using a directory name and receive accurate results.
3. Unauthorized users are prevented from accessing directory details and receive an appropriate error or access denied message.
